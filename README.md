# FoF Scavenger Hunt

![License](https://img.shields.io/badge/license-MIT-blue.svg)

A [Flarum](https://flarum.org) extension. Hide collectable parts around your forum and let members hunt them down to build seasonal collectables — a snowman in winter, a lantern during Ramadan, a treasure chest during a promotion.

## Installation

```sh
composer require fof/scavenger-hunt:"*"
```

## Updating

```sh
composer update fof/scavenger-hunt
php flarum migrate
php flarum cache:clear
```
